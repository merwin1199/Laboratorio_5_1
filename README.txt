LABORATORIO 5.1 - DISEÑO DE INTERFACES DE USUARIO

Nombre: Merwin Arciniegas Remolina

Descripción:
Este proyecto consiste en la creación de una página web responsiva
utilizando HTML5, CSS y Bootstrap 5.3.

El sitio fue diseñado como un portafolio personal y contiene diferentes
páginas interconectadas para mostrar información, proyectos y un formulario
de contacto.

Tecnologías utilizadas:
- HTML5
- CSS3
- Bootstrap 5.3
- JavaScript para la validación del formulario

Páginas del proyecto:
- index.html: Página principal.
- portafolio.html: Página con los proyectos.
- proyecto.html: Detalle de los proyectos.
- contacto.html: Formulario de contacto.

Recursos:
- Imágenes SVG creadas para el proyecto.
- Bootstrap 5.3 mediante CDN.

Características:
- Diseño responsivo para computadores, tabletas y celulares.
- Barra de navegación creada con Bootstrap.
- Tarjetas Bootstrap para presentar proyectos.
- Formulario de contacto con validación.
- Estilos personalizados mediante CSS.
- Estructura HTML5 utilizando elementos semánticos.

Estructura del proyecto:
- index.html
- portafolio.html
- proyecto.html
- contacto.html
- style.css
- README.txt
- images/
