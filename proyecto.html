Detalle de proyectos

Información sobre los proyectos presentados

Diseño de página web

Este proyecto consiste en la creación de una página web utilizando HTML5 para organizar la información y CSS para personalizar su apariencia.

También se utiliza Bootstrap para incorporar componentes como botones, navegación, tarjetas y diferentes elementos responsivos.

Interfaz responsiva

El segundo proyecto se enfoca en crear una interfaz que pueda adaptarse correctamente a diferentes tamaños de pantalla.

Bootstrap permite utilizar un sistema de columnas y componentes que facilita la adaptación del contenido a computadores, tabletas y teléfonos celulares.

Herramientas utilizadas

HTML5

Estructura y organización del contenido.

CSS

Diseño y personalización visual.

Bootstrap

Componentes y diseño responsivo.
